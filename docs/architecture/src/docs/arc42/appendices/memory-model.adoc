==== Invalidation

A record whose evidence fingerprint changes is not necessarily false. It becomes suspect and should move to a state such as `NEEDS_REVALIDATION` or `STALE` until the system or an authorized human establishes its current validity.

==== Append-Oriented Knowledge Evolution

If `MEM-103` says RabbitMQ is used and the project migrates to Kafka, the preferred history is a successor record that supersedes the previous knowledge. Historical context remains traceable.

==== Memory Format Benchmark — Required Before Final ADR

Candidate formats: JSON, YAML, XML, TOML, Markdown and a custom compact representation.

Benchmark dimensions:

* token consumption across target providers;
* parse accuracy;
* generation accuracy;
* round-trip fidelity;
* schema adherence;
* latency;
* cost;
* Git diff readability;
* merge behavior;
* tooling maturity;
* canonical-to-AI projection complexity.

The architecture must allow canonical and AI-facing formats to differ.
