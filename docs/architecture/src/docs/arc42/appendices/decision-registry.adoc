=== Decision Registry

This registry summarizes the authoritative architecture decisions for Praetor. It is intended to make the closure points explicit and to prevent silent reinterpretation during implementation.

==== Decision Closure Rule

A decision marked DEFERRED or BENCHMARK/SPIKE REQUIRED MUST NOT be silently resolved by an implementation task or AI agent.

When a milestone reaches a trigger for such a decision, the following must occur before dependent implementation may continue:

. dependent implementation must stop;
. the required benchmark/spike/research must be completed;
. an ADR or explicit architecture decision must be produced;
. human approval must be obtained;
. implementation may resume only after approval.
