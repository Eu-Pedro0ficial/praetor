=== Decision Registry

This registry mirrors the actual ADR files and their stated statuses. ADRs
provide authoritative context and consequences; Roadmap V2 open gates are
indexed in `docs/roadmap/OPEN_DECISIONS.md`.

==== Decision Closure Rule

A decision marked `DEFERRED`, `BENCHMARK REQUIRED`, `SPIKE REQUIRED`,
`PROPOSED`, or otherwise undecided must not be silently resolved by an
implementation task or AI agent. Dependent implementation stops until the
required evidence, ADR or explicit decision, and human approval exist.
