=== AI Produces Isolated Proposed Changes Before Acceptance

*Status:* ACCEPTED

*Context:* Direct writes by agents blur proposal and accepted source state.

*Decision:* Use Git worktrees as the initial source/workspace isolation mechanism, extract a patch, validate it, then apply only accepted changes. Worktree isolation is not itself a security sandbox; stronger process/container/OS isolation requires a separate security spike and ADR before being claimed for untrusted workloads.

*Consequences:* Safer rollback/control and cleaner audit. Platform-specific sandbox strategy remains a future concern for stronger security boundaries.
