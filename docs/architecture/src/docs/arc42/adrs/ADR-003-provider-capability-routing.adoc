=== Route AI Providers by Capabilities and Governance

*Status:* ACCEPTED

*Context:* Roles need different model capabilities, and providers may change.

*Decision:* Model provider adapters expose capabilities. Agent Router chooses an allowed provider based on role requirements plus data/trust policy rather than hard-coded provider names. The provider trust taxonomy is LOCAL, ENTERPRISE, EXTERNAL_APPROVED, EXTERNAL_RESTRICTED, FORBIDDEN; the data classification taxonomy is PUBLIC, INTERNAL, CONFIDENTIAL, RESTRICTED. Roadmap V2 assigns routing implementation to M3.0; M0.5 manual selection remains a distinct implemented subset.

*Consequences:* Provider independence improves. Capability normalization and routing policy become core responsibilities. Future taxonomy changes require architecture review and approval.
