=== Performance Direction

No hard latency SLO is yet approved. The architecture should minimize unnecessary model calls by using deterministic repository analysis and retrieval before semantic/LLM processing. Local memory lookup should be fast enough for interactive CLI use; precise budgets are TBD and should be benchmarked.

=== Reliability Direction

Workflow state and canonical memory/source transitions must be recoverable after process interruption. AI/provider invocations are assumed non-deterministic and potentially transient; durable state must not depend on in-memory conversation state alone.
