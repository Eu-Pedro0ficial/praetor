=== Known Architectural Debt at Baseline

With implementation complete through M1.0, the principal remaining debt is
**future-gate and implementation debt**, not an unimplemented V0 loop. M1.1
durability decisions are closed, but their runtime is not implemented.
Canonical application
is deliberately local and working-tree-only. Its adapter lock coordinates one
process; concurrent external Git writers are detected by repeated preflight or
post-application proof but are not claimed to be prevented by a repository-wide
multi-process lock. The most important deferred items are
the canonical memory serialization benchmark, hosted organization memory,
semantic conflict detection, M3.0 provider routing/trust enforcement,
multi-provider maturity, stronger sandboxing beyond the approved worktree
strategy, and M1.5's concrete tool portfolio/final assurance taxonomy. These
items remain explicitly gated by their milestones, benchmark, ADR and human
approval rather than silently being implemented.
