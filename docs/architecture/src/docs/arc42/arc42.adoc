== Document Purpose

This document is the architecture baseline for Praetor, a software engineering governance runtime in which AI agents are replaceable, constrained executors rather than autonomous owners of the development process. The system is designed primarily for controlled maintenance and evolution of existing and legacy software, while remaining usable for greenfield work.

The product name is officially **Praetor**. The repository name is **praetor** and the CLI executable is **praetor**.
